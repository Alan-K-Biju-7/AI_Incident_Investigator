# AI system

The default provider is a deterministic offline investigator. A provider adapter can supply structured hypotheses while the application retains schema validation, retrieval, confidence, temporal ordering, and stopping control. The planned tool surface includes evidence/log search, metric queries, Git inspection, architecture lookup, incident memory, hypothesis comparison, and sandboxed numerical analysis.

The loop observes evidence, chooses the highest-information tool, updates competing hypotheses, searches for contradictions, and stops at the configured threshold, diminishing retrieval gain, or iteration budget. Agent replay stores concise action rationale and results; it never persists hidden chain-of-thought.
